    O Problema do Pedágio

    Uma rede de estradas com pedágios


    • A autoridade define os pedágios \(x\).
    • O motorista escolhe a rota de acordo com o custo da viagem.
    • Como a autoridade decide o valor do pedágio?
    Figura adaptada do TikZ de projeto.tex, Figura 6. Os custos das rotas são c₁ e c₂ + x. O empate ocorre em x = c₁ − c₂.

    Modelando o problema do pedágio

    • A autoridade deseja maximizar o lucro: \[ \max_{x \in \mathbb R}\quad xy. \]
    • \( y \) é uma variável controlada pelo motorista: \[ y = \argmin_{z \in\{0, 1\}}\quad c_1( 1 - z ) + ( c_2 + x )z. \]
    • \( y \) não está bem definida quando \( c_1 = c_2 + x \).
    • Observe que a dificuldade seria a mesma com \( z \in [0, 1] \).

    Resolvendo o empate cooperativamente

    \[ \begin{aligned} \max_{x, y}\quad & xy \\ \st\quad & y \in \argmin_{z \in\{0, 1\}}\quad c_1( 1 - z ) + ( c_2 + x )z. \end{aligned} \]
    • O otimizador é \( ( x^*, y^* ) = ( c_1 - c_2, 1 ) \).
    • Assumimos que o motorista irá preferir ir pela via pedagiada quando os custos são iguais.
    • O modelo assume informação perfeita.
    • Observe que o resultado seria o mesmo com \( z \in [0, 1] \).

    Otimização Bilevel Otimista

    Formulação otimista

    Definamos o conjunto de respostas racionais: \[ \mathcal F( \bm x ) := \argmin_{\bm y \in Y( \bm x )} \quad g( \bm x, \bm y ). \]
    A formulação otimista de um problema de otimização em dois níveis pode ser escrita como: \[\tag{$\mathscr{O}$}\label{eq_optimistic} \begin{split} \min_{\bm x, \bm y} & \quad f( \bm x, \bm y )\\ \st& \quad \bm x \in X\\ & \quad \bm y \in \mathcal F( \bm x ), \end{split} \]
    Mostrar onde ocorre o empate na rede e como a resposta favorável afeta o objetivo.

    Formulação otimista

    \[ \begin{split} \min_{\bm x, \bm y} & \quad f( \bm x, \bm y )\\ \st& \quad \bm x \in X\\ & \quad \bm y \in \mathcal F( \bm x ) = \argmin_{\bm z \in Y( \bm x )} \quad g( \bm x, \bm z ). \end{split} \]
    • Quando há empates para o seguidor, a líder decide.
    • A abordagem cooperativa para o pedágio é um caso particular.
    • Em geral, a líder pode influenciar o conjunto viável do seguidor.

    Otimização Bilevel Pessimista

    Formulação pessimista

    Definamos a resposta de custo maximal: \begin{equation} f( \bm x ) := \max_{\bm y \in \mathcal F( \bm x )} f( \bm x, \bm y ). \end{equation}
    Definimos, então, o conjunto de respostas pessimistas como: \begin{equation} \mathcal P( \bm x ) := \bigl\{ \bm y \in \mathcal F( \bm x ) : f( \bm x, \bm y ) = f( \bm x ) \bigr\}. \end{equation}
    O problema de otimização em dois níveis pessimista é \begin{equation}\tag{$\mathscr{P}$}\label{eq_pessimistic} \begin{split} \min_{\bm x, \bm y} & \quad f( \bm x, \bm y )\\ \st & \quad \bm x \in X\\ & \quad \bm y \in \mathcal P( \bm x ). \end{split}\quad\Leftrightarrow\qquad \begin{split} \min_{\bm x} & \quad f( \bm x )\\ \st & \quad \bm x \in X. \end{split} \end{equation}
    Usar o exemplo para mostrar a dificuldade que surge no ponto de empate e discutir se o ínfimo é atingido.

    Resolvendo o empate antagonicamente

    A formulação pessimista do problema do pedágio fica \[ \begin{aligned} \max_{x}\min_{y}\quad & xy \\ \st\quad & y \in \argmin_{z \in\{0, 1\}}\quad c_1( 1 - z ) + ( c_2 + x )z. \end{aligned} \]
    • Com custos iguais, o motorista prefere não pagar pedágio.

    Resolvendo o empate antagonicamente

    Na formulação pessimista do problema do pedágio:
    • \[ \mathcal F( x ) = \begin{cases} \{ 1 \} &\text{se } c_2 + x < c_1\\ \{ 0, 1 \} &\text{se } c_2 + x = c_1\\ \{ 0 \} &\text{se } c_2 + x > c_1. \end{cases} \]
    • \[ \mathcal P( x ) = \begin{cases} \{ 1 \} &\text{se } c_2 + x < c_1\\ \{ 0 \} &\text{se } c_2 + x \ge c_1. \end{cases} \]
    • \[ f( x ) = \begin{cases} x &\text{se } c_2 + x < c_1\\ 0 &\text{se } c_2 + x \ge c_1. \end{cases} \]
    • O otimizador não existe!

    Otimização Bilevel Ponderada

    Formulação ponderada

    Mallozzi e Morgan [1] consideram uma abordagem intermediária: \begin{equation}\tag{$\mathscr{W}$}\label{eq_weighted} \begin{split} \min_{\bm x} & \quad F( \bm x ) := \int_{\mathcal F( \bm x )} f( \bm x, \bm y )\mathrm d\mu_{\bm x}\\ \st & \quad \bm x \in X, \end{split} \end{equation} onde, para cada \( \bm x \), \( \mu_{\bm x} \) é uma medida de probabilidade.

    • A integração é com relação a $\bm y$.
    • Contém os casos otimista e pessimista.
    • É capaz de modelar uma população de seguidores.
    • Não resolve a ausência de solução.
    Explicitar a distribuição usada no exemplo e mostrar o comportamento do objetivo esperado.

    Resolvendo o empate ponderadamente

    A formulação ponderada do problema do pedágio fica \[ \max_{x}\quad F( x ) = \int_{\mathcal F( x )}xy\mathrm d\mu_{x} \] com \[ \mathcal F( x ) = \argmin_{z \in\{0, 1\}}\, c_1( 1 - z ) + ( c_2 + x )z. \]
    • Com custos iguais, alguns motoristas preferem não pagar pedágio, enquanto outros preferem pagar.
    • A medida \( \mu_x \) modela as proporções de motoristas que fazem cada escolha.

    Resolvendo o empate ponderadamente

    Na formulação ponderada do problema do pedágio:
    • \[ \mathcal F( x ) = \begin{cases} \{ 1 \} &\text{se } c_2 + x < c_1\\ \{ 0, 1 \} &\text{se } c_2 + x = c_1\\ \{ 0 \} &\text{se } c_2 + x > c_1. \end{cases} \]
    • \[ F( x ) = \begin{cases} x &\text{se } c_2 + x < c_1\\ x\alpha &\text{se } c_2 + x = c_1\\ 0 &\text{se } c_2 + x > c_1. \end{cases} \]
    • \( \alpha \in [ 0, 1 ] \) codifica \( \mu_x \) para \( x = c_1 - c_2 \).
    • O otimizador só existe com \( \alpha = 1 \), ou seja, o caso otimista!

    Otimização Bilevel com Irracionalidade

    Formulação com racionalidade limitada

    \[\tag{$\mathscr{P_\epsilon}$}\label{eq_wies} \begin{align} \min_{\bm x, \bm y} \quad & f( \bm x, \bm y )\\ \st \quad & \bm x \in X\\ & \bm y \in \mathcal P_\epsilon( \bm x ), \end{align} \] onde

    • \[ g( \bm x ) := \min_{\bm y \in Y( \bm x )} g( \bm x, \bm y ). \]
    • \[ \mathcal F_\epsilon( \bm x ) := \{ \bm y \in Y( \bm x ) : g( \bm x, \bm y ) \le g( \bm x ) + \epsilon \}. \]
    • \[ \mathcal P_\epsilon( \bm x ) := \argmax_{\bm y \in \mathcal F_\epsilon( \bm x )}\quad f( \bm x, \bm y ). \]

    Apresentar a derivação do limite usando a rede de pedágios.

    Resolvendo o empate com racionalidade limitada

    • \[ g( x ) + \epsilon = \begin{cases} \epsilon + c_2 + x &\text{se } c_2 + x < c_1\\ \epsilon + c_1 &\text{se } c_2 + x \ge c_1. \end{cases} \]
    • \[ \mathcal F_\epsilon( x ) = \begin{cases} \{ 1 \} &\text{se } c_2 + x \le c_1 - \epsilon\\ \{ 0 \} &\text{se } c_2 + x \ge c_1 + \epsilon\\ \{ 0, 1 \} &\text{caso contrário}. \end{cases} \]
    • \[ \mathcal P_\epsilon( x ) = \begin{cases} \{ 1 \} &\text{se } c_2 + x \le c_1 - \epsilon\\ \{ 0 \} &\text{se } c_2 + x \ge c_1 + \epsilon\\ \{ 0 \} &\text{caso contrário}. \end{cases} \]
    • O otimizador existe para todo $\epsilon > 0$.

    Propriedades da formulação com racionalidade limitada

    Wiesemann et al. [2] introduziram a ideia e mostraram algumas propriedades.

    • Se $Y( \bm x ) \equiv Y$ e $\epsilon > 0$, então uma solução existe.
    • Com \( \epsilon = 0 \) temos o caso pessimista.
    • O limite para $\epsilon \to 0^+$ existe.
    • Entretanto, nosso exemplo mostra que o limite para $\epsilon \to 0^+$ pode ser igual à solução otimista.

    Otimização Bilevel com Ponderação e Irracionalidade

    Formulação com ponderação e racionalidade limitada

    A fim de aumentar o poder de modelagem e obter mais possibilidades teóricas, propomos um modelo que une a ponderação com a irracionalidade limitada: \[\tag{$\mathscr{W}_\epsilon$}\label{eq_wi} \begin{split} \min_{\bm x} & \quad A( \bm x ) := \int_{\mathcal F_\epsilon( \bm x )} f( \bm x, \bm y )\mathrm d\mu_{\bm x}\\ \st & \quad \bm x \in X. \end{split} \]
